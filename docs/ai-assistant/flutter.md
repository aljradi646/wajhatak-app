# تكامل Flutter — المساعد الذكي

> ملاحظة: هذا الملف هو المرجع السابع المطلوب (Flutter integration) ضمن حزمة وثائق المساعد، ويغطي كل ما يخص الطرف العميل.

## الملفات

| الملف | الدور |
|---|---|
| `lib/data/models/ai_assistant.dart` | `AiPropertyResult` (بطاقة عقار حقيقية)، `AiBootstrap` (إعدادات الواجهة)، `AiChatMessage` |
| `lib/data/repositories/ai_assistant_repository.dart` | الاتصال بـ Laravel عبر `LuxApiClient` الحالي (نفس التوكن/الثروتل/التحدي) + تخزين مفتاح جلسة الزائر في `SharedPreferences` |
| `lib/state/ai_assistant_controller.dart` | حالة المحادثة (رسائل + انتظار + خطأ) عبر Riverpod `Notifier` مع تدهور آمن وإعادة إرسال |
| `lib/ui/screens/ai/ai_assistant_sheet.dart` | نافذة المحادثة: Bottom Sheet للجوال، Dialog متمركز للشاشات ≥1024px |
| `lib/ui/screens/shell/app_shell.dart` | الزر العائم «المساعد الذكي» (للمستخدمين المسجلين، فوق الشريط السفلي يسارًا) |

## نقاط التصميم

- **بلا مكتبات جديدة**: كل شيء بالاعتماد على `dio` و`flutter_riverpod` و`shared_preferences` الموجودة في `pubspec.yaml` — لا يتغير إصدار أي حزمة.
- **البطاقات حقيقية**: `_AiPropertyMiniCard` يعرض فقط ما أرسله الخادم (صورة/سعر/موقع/غرف/حمامات/مساحة/توفر). زر «التفاصيل» يفتح `PropertyDetailScreen(propertyId)` الفعلية — نفس شاشة تفاصيل التطبيق، وزر القلب يستدعي `toggleFavorite` الرسمي، فكل عمليات الحفظ على العقار الحقيقي.
- **السياق على الخادم**: التطبيق لا يدير المعايير؛ يرسل `conversation_id` (للمسجلين) أو `session_token` محفوظ محليًا (للزوار) ويتلقى الرد والنتائج.
- **الاقتراحات**: تُجلب من الخادم (`/ai/bootstrap`) — قابلة للتغيير من لوحة الإدارة دون تحديث التطبيق.
- **النسخ**: ضغط مطول على أي فقاعة ينسخ نصها.
- **الإغلاق/المسح/إعادة الإرسال**: أزرارAppBar (مسح، إغلاق) + شريط إعادة إرسال يظهر عند آخر فشل فقط.

## مواضع الظهور

الزر يظهر في `AppShell` فقط (كل تبويبات التطبيق) عندما توجد جلسة مستخدم. لعرض المساعد من أي شاشة أخرى:

```dart
import '../ai/ai_assistant_sheet.dart';
showAiAssistant(context);
```

الدالة تختار النافذة المناسبة تلقائيًا حسب عرض الشاشة.

## تدهور آمن (لا تنكسر الواجهة أبدًا)

| الحالة | ما يراه المستخدم |
|---|---|
| 503 (المساعد معطل) | «المساعد غير متاح حاليًا، لكن يمكنك استخدام البحث العقاري التقليدي.» |
| انقطاع شبكة/مهلة | رسالة في المحادثة + زر «إعادة إرسال» — بقية التطبيق سليمة |
| فشل `/ai/bootstrap` | قيم افتراضية محلية (الاسم + الترحيب) حتى يعود الاتصال |
