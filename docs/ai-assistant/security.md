# الأمان — المساعد الذكي

## 1. النموذج المقنن (Threat Model)

| التهديد | الحماية المطبقة |
|---|---|
| حقن تعليمات (Prompt Injection) | `AiGuardrailService::isPromptInjection()` — أنماط عربية/إنجليزية في الكود، تُرفض قبل الاستدلال. + قاعدة system رقم 4/5 تمنع الكشف حتى لو مرّت |
| خارج النطاق (كود/واجبات/عام) | مصنف طلبات في الكود (كلمات نطاق عقاري مقابل كلمات خارجية) + system rule رقم 7 |
| هلوسة معرفات/أسعار | `AiResponseGroundingService` — التحقق بعد التوليد **إلزامي لا يمكن تعطيله من اللوحة** |
| كشف بيانات حساسة | فحص مسبق للطلب + فحص المخرجات (`leaksSecrets`) يستبدل الرد بالكامل عند التسرب |
| وصول النموذج للقاعدة | النموذج لا يملك اتصال DB إطلاقًا — يعمل خلف Laravel فقط عبر أدوات القائمة البيضاء |
| تخمين محادثات الآخرين | ملكية صارمة: `user_id` للمسجلين، `session_token` عشوائي 64-hex للزوار مع `hash_equals` |
| رفع المعدل | `throttle:api` العام + RateLimiter خاص بالمساعد (10/د للمحادثة، 30/د للبحث) لكل مستخدم أو IP |
| التلاعب من لوحة الإدارة | 3 حواجز مقفلة في الكود (`FORCED_TRUE`): الهلوسة، الحقن، الحساسية — لا يمكن إيقافها من الواجهة |

## 2. عزل الأسرار

- `AI_INFERENCE_API_KEY` وبيانات DB لا تُقرأ في أي استجابة API، ولا تُسجل، ولا تظهر في Blade.
- `/api/v1/ai/health` تعيد `healthy` و`latency_ms` فقط — لا أسماء نماذج أو عناوين شبكة.
- `/api/v1/ai/bootstrap` تعيد (الاسم، الترحيب، الاقتراحات) فقط.
- سجل `ai_request_logs` يحفظ: نية مختصرة، معايير منظمة، أدوات، عدّادات، زمن. **لا يحفظ** نص الرسالة الحرة ولا رد النموذج ولا التوكنات.

## 3. حماية System Prompt

قواعد السلامة تُبنى في `AiPromptService::responseSystemPrompt()` **داخل الكود**؛ نص الإدارة (`ai_system_prompt`) يُلحق *بعد* القواعد مع تعليمة صريحة بعدم التعارض معها. لا يوجد مسار يتيح لمسؤول تعديل القواعد الثمان أو حذفها، وفحص الحقن يمنع طلبات «اعرض تعليماتك» قبل أن تصل للنموذج.

## 4. عزل الشبكة

```
Internet → Laravel (TLS, HTTPS forced) → AI Inference (شبكة خاصة فقط)
```

- خادم الاستدلال **لا يُكشف للإنترنت إطلاقًا**: `HOST=0.0.0.0` داخل VPC/شبكة Docker، أو `127.0.0.1` إن كان محليًا.
- Flutter يتصل بـ Laravel فقط — لا يوجد أي مسار من العميل إلى النموذج (لا CORS، لا endpoint مكشوف).
- Railway حاليًا لا يشغّل GPU: النموذج يُنشر على خادم منفصل ويُقيد الوصول بـ IP allowlist أو VPN/WireGuard.

## 5. حدود صارمة

| الحد | القيمة | المكان |
|---|---|---|
| طول رسالة المستخدم | 600 حرف | `AiChatRequest` + config |
| عدد النتائج المعروضة | ≤ 6 | سقف في `AiSettingsService` (لا تتجاوزه اللوحة) |
| عدد المترشحين قبل التسجيل | ≤ 60 | نفسه |
| أسئلة المتابعة المتتالية | 3 | `config('ai.limits.max_followups')` |
| درجة الحرارة | ≤ 1.0 | سقف مفروض في `AiSettingsService` |
| مهلة النموذج | 30s (افتراضيًا) | `LocalGlmProvider` مع مهلة اتصال 5s |
| طول مخرجات النموذج | 700 token | إعداد + سقف |

## 6. ماذا لو تعرض النموذج لحث خارج رسالة المستخدم؟

قطع DATA تُبنى بـ templates PHP — لا يمر فيها أي نص مستخدم. رسالة المستخدم تصل كرسالة `user` منفصلة؛ أي تعليمات داخلها تُعامل كنص طلب (وبالحاجز المسبق تُرفض إن كانت أنماط حقن)، بينما الأدوات والاستعلام يبنيهما Laravel حصريًا من معايير مُتحقق منها — لا يمكن لرسالة المستخدم أن تضيف SQL أو تجاوز الفلاتر.
