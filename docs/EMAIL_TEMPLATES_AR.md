# نظام قوالب البريد

يدعم النظام قالبًا حقيقيًا محفوظًا في قاعدة البيانات، معاينة HTML، المتغيرات، التفعيل/التعطيل، النسخ، وسجل إصدارات مستقل قابل للاستعادة.

كل تحديث يحفظ نسخة سابقة قبل تعديل القالب. الاستعادة تنشئ إصدارًا جديدًا بدل الكتابة فوق التاريخ.

لا تُخزن أسرار SMTP أو Resend داخل قالب البريد.
